# 工作目录说明

本目录存放"探迹 CRM 客户数据全量导出"任务中使用的全部脚本代码。
（原始代码此前都写在浏览器控制台注入环境里，本次已全部整理为本地文件。）

## 目录结构

```
G:\1\探迹客户数据\
├── 工作目录\          ← 本目录（代码）
│   ├── 01_电话解密算法.js           Hot联系方式加密串的解密函数（可独立运行自测）
│   ├── 02_浏览器注入_采集脚本.js    控制台注入：拉取+解析+拟人化限速+自动落盘
│   ├── 03_游标翻页_突破一万上限.js  突破 ES 10000 条偏移上限的游标试探脚本
│   ├── 04_生成MD分片.py             全量 JSON → 每 100 条一个 MD 文件
│   ├── 05_汇总Excel.py              全量 JSON → 汇总 Excel（无 openpyxl 时降级 CSV）
│   └── README_使用说明.md           本文件
├── 结果目录\          ← 数据成果
│   ├── 客户数据_前10000条_备份.json 已到手的前 10000 条（浏览器内存抢救版）
│   ├── 客户数据_全量.json           （待生成）全部 25743 条
│   ├── 客户数据汇总.xlsx            （待生成）
│   └── md\客户数据_NNN.md           （待生成）每 100 条一个分片
└── 工作任务记录.md    ← 方法、时间线、问题与解决过程全记录
```

## 标准作业流程

1. 登录 `https://crm.tungee.com/customers/following`（客户管理）
2. F12 控制台粘贴 `02_浏览器注入_采集脚本.js`（只安装不狂跑）
3. `await __runBatch(0, 10000)` —— 拉前 1 万条（偏移上限内）
4. `__exportAll()` —— JSON 落盘到下载目录（G:\1），改名备份
5. 突破 1 万上限：粘贴运行 `03_游标翻页_突破一万上限.js` 看探测结果，
   游标生效后用 `__runBatch(10000, 25743)` 续传（脚本内含游标逻辑）
6. `python 04_生成MD分片.py` + `python 05_汇总Excel.py` 生成最终成果

## 拟人化限速参数（内置在 02 号脚本）

| 项 | 值 |
| --- | --- |
| 每页条数 | 200（与前端页面分页一致） |
| 页间隔 | 随机 4~9 秒 |
| 长休息 | 每 10 页左右停 15~30 秒 |
| 失败退避 | 60 秒后重试，最多 3 次 |
| 自动落盘 | 每 20 页下载一次进度 JSON |
